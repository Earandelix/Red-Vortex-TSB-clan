RED VORTEX ULTRA WEBSITE
=========================
Open index.html in a browser.

Included:
- Red Vortex logo
- Discord invite
- Animated particle field
- Boot/loading screen
- Responsive mobile navigation
- Hero section
- Clan intelligence cards
- Live-style terminal/radar panel
- Searchable/filterable roster
- Member profile modal
- Recruitment requirements
- Interactive rules tabs
- FAQ accordion
- Animated stat counters
- Scroll reveals
- Magnetic buttons
- Mobile responsive layout

To edit members:
Open script.js and change the `members` array.

To deploy:
Upload index.html, style.css, script.js, and logo.jpeg to any static hosting service.
